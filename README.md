# 三麻ログPWA

四人一抜け三麻を、益田視点で記録するためのPWAです。

## 目的

このアプリは、益田が参加した局を中心に、結果・点数移動・対局姿勢・主観タグを記録し、CSVとして出力するためのものです。

アプリ内で高度な分析までは行わず、記録・保存・CSV出力を主目的とします。CSVをChatGPTに添付することで、益田たちのハウスルール前提で戦力分析を行う運用です。

## 基本仕様

- 固定メンバー：益田、水戸、渋谷、松林
- 四人で半荘開始
- 各局の北家が抜け番
- 東1局〜東4局、南1局〜南4局
- 親継続／親流れは手動選択
- 半荘収支は後日入力可能
- データは使用端末のlocalStorageに保存
- GitHubには対局データは自動送信されません

## 記録するもの

- ロン和了
- ツモ和了
- ロン放銃
- ツモられ
- 被害なし
- 流局
- 入力困難スキップ
- 対局姿勢
- 主観タグ
- 半荘収支

## 記録しないもの

- 益田が関与しない他家同士の細かい点数移動
- 牌姿
- 捨て牌
- 巡目
- 役判定
- 自動点数計算

## 更新方法

### 1. アプリ本体を更新する場合

GitHubリポジトリ直下のファイルを上書きします。

必要ファイル：

```text
index.html
manifest.json
version.json
sanma_v140_apple_touch_icon.png
sanma_v140_favicon.png
sanma_v140_icon_192.png
sanma_v140_icon_512.png
```

アップロード後、GitHub Pagesの反映を待ち、Safariまたはホーム画面アプリから「アプリ更新」画面を開き、最新版を読み直します。

### 2. 保存済みデータ形式を補正する場合

アプリ内の「システム」画面から「保存データ形式を現在形式に補正」を実行します。

これは、端末内のlocalStorageにある過去データの不足項目を補正するための機能です。  
アプリ本体をGitHubから更新する機能ではありません。

## iPadで古いバージョンが表示される場合

- SafariでURLを直接開く
- アプリ内の「アプリ更新」から最新版を読み直す
- URL末尾に `?reload=任意の数字` を付ける
- ホーム画面アイコンを削除して再追加する

## CSV出力

局ログCSVと半荘CSVを出力できます。  
取消済みログは通常CSVには出力されません。

## データ保存

対局データは、使用端末のlocalStorageに保存されます。  
端末を変えるとデータは共有されません。


## v2.0.0 点数ボタン制御

結果・益田の親子・相手の親子に応じて、使用しない点数ボタンは灰色になり選択できません。

通常ボタンにないレアケースは「イレギュラー入力」から1000点単位で入力します。  
例：親のトリプル役満ツモられ等で通常候補にない場合。

## v2.1.0 レイアウト調整

エケベリア管理アプリの構造を参考に、アプリ全体を max-width:520px のシェルに収め、header・main・下部タブバーの配置を調整しました。

## v2.4.0 主観タグ複数選択化

主観タグを複数選択可能に変更しました。  
タグ同士の排他制御は行わず、結果種別ごとに候補を切り替えます。

### 和了時
押し成功 / リーチ判断成功 / 鳴き判断成功 / カン判断成功 / 枚数把握不安 / 問題無し

### ロン放銃時
押しすぎ / 安手で押しすぎ / テンパイ固執 / オリ判断ミス / 現物なし / 安全牌不足 / スジ引っかけ / 生牌切り / ドラそば / 染め手見落とし / 待ち読みミス / リーチ判断ミス / 鳴き判断ミス / 鳴き対応ミス / カン判断ミス / 問題無し

### ツモられ時
速度負け / ベタ降り中 / 押し返し中 / テンパイ崩し / 問題無し

### 流局時
形式テンパイ / オリ完了 / テンパイ崩し / 回し打ち成功 / 問題無し
